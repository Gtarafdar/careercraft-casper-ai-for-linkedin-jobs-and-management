## Justification Statement (if requested)

```
This extension requires specific permissions to provide its core functionality:

1. activeTab: Inject formatting toolbar and AI features into active LinkedIn tabs
2. storage: Store user preferences, API keys (encrypted), and cached data locally
3. clipboardRead: Enable image paste from clipboard into LinkedIn posts
4. notifications: Alert users of new job postings matching saved searches
5. alarms: Schedule periodic job search checks at user-defined intervals
6. scripting: Dynamically inject content scripts (required for Manifest V3)
7. tabs: Manage LinkedIn tab interactions for job notifications

Host permissions:
- linkedin.com: Core functionality domain
- generativelanguage.googleapis.com: User's Google Gemini API
- api.openai.com: User's OpenAI API
- careercraftai-extension.infonyxto.workers.dev: License validation service

All data is stored locally. No user tracking or analytics. Users provide their own AI API keys.
```

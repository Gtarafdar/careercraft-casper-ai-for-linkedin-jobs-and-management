# 🚀 Quick Start Guide

Get your LinkedIn Text Formatter & AI ATS Analyzer extension up and running in 3 minutes!

## Installation (30 seconds)

1. Open Chrome and go to: `chrome://extensions/`
2. Enable **Developer mode** (toggle in top-right)
3. Click **Load unpacked**
4. Select the folder: `Linkedin Text Formater and Image Uploder`
5. Done! ✅

## First Use (30 seconds)

1. Go to [LinkedIn.com](https://linkedin.com)
2. Click **"Start a post"**
3. See the toolbar appear! 🎉

## Quick Features Test (1 minute)

### Text Formatting

1. Type: "Hello World"
2. Select "World"
3. Click **𝐁** button
4. Result: "Hello 𝐖𝐨𝐫𝐥𝐝"

### Typography Styles

1. Select any text
2. Click **Aa** button
3. Choose a style from the dropdown
4. Your text is now styled! ✨

### Paste Images

1. Take a screenshot (Win+Shift+S or Cmd+Shift+4)
2. Click in the LinkedIn post editor
3. Paste with Ctrl+V (or Cmd+V)
4. Image uploads automatically! 📸

## Toolbar Buttons Explained

```
[𝐁] = Bold           [•] = Bullet List
[𝐼] = Italic         [1.] = Numbered List
[U̲] = Underline      [🔗] = Insert Link
[S̶] = Strikethrough  [😊] = Emoji
[Aa] = Typography Styles (11 different fonts!)
```

## Pro Tips

✅ **Always select text first** before clicking format buttons
✅ **Typography dropdown** has 11 unique styles - try them all!
✅ **Paste images directly** - no need to use LinkedIn's image button
✅ **Check console (F12)** if something doesn't work - helpful debug messages

## Common Issues

❌ **Toolbar not showing?**

- Refresh the LinkedIn page (F5)
- Make sure extension is enabled in chrome://extensions/

❌ **Image paste not working?**

- Make sure you copied an actual image (not a file path)
- Click inside the text editor first

❌ **Format not applying?**

- Did you select the text first?
- Try clicking elsewhere and reselecting

## AI-Powered ATS Analysis (NEW!)

### Get Free API Key (1 minute)

1. Go to: [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Sign in with Google
3. Click **Create API Key**
4. Copy the key (starts with "AIza...")

### Configure Extension (30 seconds)

1. Click extension icon in Chrome toolbar
2. Click **⚙️ Settings**
3. Select **Gemini** radio button
4. Paste your API key
5. Click **Save**

### Use AI Analysis

1. Go to [LinkedIn Jobs](https://linkedin.com/jobs)
2. Click on any job to open details
3. Wait 5-10 seconds
4. See your AI-powered compatibility score! 🤖

**Results show:**

- Overall compatibility score (0-100%)
- Skills match analysis
- Experience level fit
- Your strengths for this job
- Areas to improve
- Personalized recommendations

## Need Help?

1. Open browser console (F12) and check for errors
2. Look for messages starting with "LinkedIn Formatter:"
3. Verify extension is enabled and has permissions
4. For AI issues, check Settings to verify API key is saved

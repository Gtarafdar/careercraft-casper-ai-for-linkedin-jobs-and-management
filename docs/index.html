Hands-on

How to use CareerCraft

  1. Install the ZIPUnzip → chrome://extensions → Developer mode → Load unpacked.
  2. Add an AI keySettings → AI API Keys. OpenRouter free models work great to start.
  3. Load your profileUpload CV, paste text, or Auto extract on LinkedIn.
  4. Run ATS on a jobOpen a role → see the score → it lands in Job Tracker.
  5. Save searches & alertsUp to 5 searches. Notify when counts rise — not every quiet check.
  6. Ask CasperGhost on a post → analyze, discuss, keep history.

FAQ

Questions people ask

Is it free?

Yes. Open source. You only pay your AI provider if you use ATS or Casper. Donations optional.

Where do my API keys go?

Chrome extension storage on your device. No CareerCraft key vault.

Can I use free or cheap models?

Yes. Connect OpenRouter and pick free or low-cost models. Or use Gemini / OpenAI / DeepSeek / Qwen with your own key.

Do alerts spam every check?

No. Notifications fire when a saved search’s job count goes up — not on quiet checks.

Chrome Web Store?

Install via GitHub Releases (Load unpacked) today. Star the repo to follow a Store listing later.

How to

Install once. Use it where you already work.

Download the release ZIP

Grab the latest package from GitHub Releases (the Download buttons resolve to the direct ZIP when a release exists).

Load unpacked in Chrome

Open chrome://extensions → enable Developer mode → Load unpacked → select the unzipped folder.

Pin & open Settings

Pin CareerCraft, open the dashboard, add an AI key if you want ATS / Casper, and upload or paste your profile.

On LinkedIn: write, hunt, track

Use the formatter on posts, save searches, open Last 1 hour, send feed hiring posts to Job Tracker, and tap the Casper ghost on any post.

Optional: alerts & feed widgets

Enable notifications in Searches & Alerts. Turn on Jobs to review and Favorite authors on the feed right rail.

Click the ghost on a post → get insights, reply angles, or strategy tips in the floating chat.

FAQ

Questions people actually ask

Is it free?

Yes. The extension is free and open source. You pay only your chosen AI provider if you use ATS or Casper. Donations are optional and appreciated.

Where do my API keys go?

They stay in Chrome’s extension storage on your device. CareerCraft does not operate a key vault for you.

Will it work when LinkedIn isn’t open?

Saved-search checks and notifications can run in the background via extension alarms. Feed widgets need you on LinkedIn.

Chrome Web Store?

Install today via GitHub Releases (Load unpacked). Store listing may come later — star the repo to follow along.

Does it scrape LinkedIn aggressively?

It enhances pages you visit and uses saved-search flows you configure. It is not a bulk scraper or auto-apply bot.

What makes it unique

ATS scoring + profile check — on LinkedIn, with your keys

Most LinkedIn tools stop at bookmarks. CareerCraft scores each role against your CV / profile before you apply — then keeps that score on the Job Tracker row.

ATS on the job page

Know the fit before you apply

  • Compatibility % injected on LinkedIn job pages
  • Must-have vs nice-to-have requirements
  • Skills, experience, education, keywords, responsibilities
  • Strengths, gaps, and a plain-language summary
  • Soft-adds the role to Job Tracker with the score

Profile check

Feed the score with your real profile

  • Upload CV / resume (PDF, DOC, DOCX, TXT)
  • Paste LinkedIn profile text by section
  • Auto extract while you are on your LinkedIn profile
  • Completeness meter (name, headline, experience, skills)
  • Stored locally — powers every ATS match

Casper AI

Hands-on

How to use CareerCraft

Install the ZIP

Download the release → unzip → chrome://extensions → Developer mode → Load unpacked.

Add an AI key

Settings → AI API Keys → Gemini, OpenAI, OpenRouter, DeepSeek, or Qwen. Keys stay local.

Load your profile

Account → upload CV, paste LinkedIn text, or Auto extract — this powers ATS match %.

Run ATS on a job

Open a LinkedIn job → see the AI-Powered ATS Analysis panel → role lands in Job Tracker with the score.

Save searches & alerts

Save up to 5 searches → enable notifications when counts rise → use Last 1 hour for freshest roles.

Ask Casper on a post

Click the ghost → post analysis, discuss replies in the chat box, or open history.

Feed & write

Feed discovery / Jobs to review · format & paste images · filter Saved items.

FAQ

Questions people actually ask

Is it free?

Yes. Free and open source. You only pay your AI provider if you use ATS or Casper. Donations are optional.

Where do my API keys go?

Chrome extension storage on your device. No CareerCraft key vault.

Can I use free or cheap models?

Yes. Connect OpenRouter and pick free or low-cost models for ATS and Casper. Or use Gemini / OpenAI / DeepSeek / Qwen with your own key — CareerCraft never adds an AI surcharge.

Do alerts spam me every check?

No. Job alerts notify when a saved search total job count goes up — not on every quiet check. First enable sets a quiet baseline.

Will it work when LinkedIn is not open?

Saved-search checks and notifications can run via extension alarms. Feed widgets need you on LinkedIn.

Chrome Web Store?

Install today via GitHub Releases (Load unpacked). Star the repo to follow a Store listing later.

Is this a scraper / auto-apply bot?

No. It enhances pages you visit and flows you configure. Not bulk people scrape, not auto-apply.

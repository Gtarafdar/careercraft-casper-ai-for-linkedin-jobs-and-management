# Icon Files Needed

The extension requires three icon sizes. You can generate them using the `generate-icons.html` file in this folder.

## Required Files:

- `icon16.png` - 16x16 pixels (for extension toolbar)
- `icon48.png` - 48x48 pixels (for extension management page)
- `icon128.png` - 128x128 pixels (for Chrome Web Store)

## How to Generate:

1. Open `generate-icons.html` in your browser
2. The icons will be automatically generated
3. Right-click each icon and select "Save image as..."
4. Save with the correct names in this folder

## Temporary Workaround:

The extension will still work without custom icons, but Chrome will show a default placeholder icon.

## Design Specifications:

**Current Design**:

- Blue gradient background (#0a66c2 to #004182)
- White "TF" text (Text Formatter)
- Small "𝐁𝐈" symbols at bottom
- Professional LinkedIn-style appearance

**Alternative Design Ideas**:

- Format brush icon
- Text with formatting marks
- LinkedIn logo integration (ensure compliance)
- Minimalist "T+" or "F" icon

## Creating Custom Icons:

You can create your own icons using:

- Adobe Photoshop/Illustrator
- Figma
- Canva
- GIMP (free)
- Any graphic design tool

**Requirements**:

- PNG format with transparency
- Square dimensions (16x16, 48x48, 128x128)
- Clear and recognizable at all sizes
- Professional appearance

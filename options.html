What is OpenRouter?

OpenRouter is a unified gateway to 400+ AI models from providers like OpenAI, Anthropic, Google, and Meta. One API key gives you access to all models with automatic fallbacks and cost optimization.

How to Get Your API Key:

  1. Visit openrouter.ai/keys
  2. Sign in with Google, GitHub, or email
  3. Click "Create Key" button
  4. Name your key (e.g., "LinkedIn ATS Analyzer")
  5. Set credit limit (optional, for budget control)
  6. Copy your key (starts with sk-or-v1-)
  7. Paste it above and click Save

🔔 Job Search Notifications

Get browser notifications when new jobs are posted for your saved searches. Notifications are OFF by default.

ℹ️ How Job Notifications Work

1. First Check (Baseline): When you enable notifications, the extension visits each saved search and records the current total job count (e.g., 1,000 jobs). This is your baseline.

2. Subsequent Checks: At your chosen interval (15-120 minutes), the extension checks each search again and compares the new total to the baseline.

3. Notifications: If the job count increased (e.g., from 1,000 to 1,005), you'll get a notification: "5 New Jobs Found - Search: 'Your Search Name'"

4. Baseline Update: After each check, the baseline is updated to the new count, so you only get notified about jobs posted since the last check.

⚠️ Important: The first time you enable notifications, you won't receive alerts immediately. The system needs to establish a baseline first. Notifications will start arriving after the second check when new jobs appear.

📊 Multiple Searches: If you have 2 saved searches, each is checked independently with its own baseline. Notifications clearly show which search triggered the alert.

🔍 Accuracy: The extension opens each search in a hidden tab to extract the total job count directly from LinkedIn. This may take 5-10 seconds per search.

📝 Learn more about the console errors and get the solution of it

ℹ️ About Console Messages (Click to expand)

You might see "Extension context invalidated" errors in the console. This is completely normal and not a bug!

Why does this happen?

  • When you reload/update the extension while LinkedIn pages are open
  • Chrome disconnects the old extension version from active pages
  • Simply refresh any LinkedIn page to reconnect to the new version

✅ Solution: Just refresh (F5) the LinkedIn page after reloading the extension. Everything will work normally!
